Android 名片即時辨識與本機聯絡人架構

以離線 OCR 為主流程；使用者鎖定候選後，背景辨識不能覆寫。完成資料存入 App 私有 SQLite，雲端 OCR 與 AI 僅在明確同意後透過受控 Gateway 使用。

即時但不覆寫

相機只交付最新影格；候選帶有掃描世代與鎖定狀態。使用者一旦鎖定文字，晚到的 OCR 結果沒有權限覆寫。

完成即入庫

使用者完成後，以一個 Room 交易寫入 App 私有 SQLite；後續查詢只透過 Repository 與 DAO，不開放資料庫檔。

外部服務是選項

雲端 OCR 與 AI 需逐次同意，並由 Gateway 保存服務端金鑰與用量規則，Android App 不攜帶共享 API key。
