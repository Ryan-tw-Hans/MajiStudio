## 3. UI 驗收條件 (UI-AC)

1. **切換順暢**：點擊「官方免設定版」或「自訂 Vercel 部署」能即時切換視圖，狀態不遺失。
2. **QR Code 清晰度**：GitHub Pages 網址之 QR Code 尺寸不小於 260x260，黑白高對比度，手機相機能在 0.5 秒內即時辨識。
3. **複製網址提示**：點擊「📋 複製網址」後按鈕文字暫態顯示「已複製！」，並在 Windows 剪貼簿寫入正確 URL。
