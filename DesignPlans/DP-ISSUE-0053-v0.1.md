## 1. 介面層級與入口設計

```
 ...
```

## 2. 「名片資料庫同步中心」對話框視覺設計

### 2.1 頂部同步管道切換器 (Mode Selector)
採用高對比雙選項分段按鈕（Segmented Button）或 Radio 卡片：
- 📁 **本地端檔案同步 (雙資料庫整併)** —— [預設選取，無需任何網路或 API 設定]
- ☁️ **Google Drive 雲端同步**

---

### 2.2 本地端檔案同步介面區塊
1. **基準與目標資料庫對照卡**：
   - **本機目前庫**：標示當前本機資料庫路徑、名片筆數。
   - **外部目標檔**：文字框（唯讀呈現選取之路徑）＋ 【📂 瀏覽選取檔案...】按鈕。
     - 支援副檔名：`*.sqlite3`, `*.db`, `*.zip`。
     - 提示標籤：可選取隨身碟、網路磁碟機或雲端同步資料夾內的資料庫。
2. **同步方向選擇 (三選一)**：
   - 🔄 **雙向整併同步 (推薦)**：兩端互相整併，有衝突由使用者裁決，整併成果寫回兩側。
   - ⬇️ **從外部檔案整併至本機**：自外部檔案提取新增/較新資料整併入目前本機。
   - ⬆️ **從本機整併至外部檔案**：將目前本機完整資料庫整併寫回外部目標檔案。

---

### 2.3 Google Drive 雲端同步介面區塊
1. **連線狀態與登入切換卡**：
   - 顯示「🟢 已連接 Google 帳號」或「⚪ 尚未登入 Google 帳號」。
2. **就地憑證設定 Expander (⚙️ Google OAuth 憑證設定)**：
   - 即使未登入，使用者也能直接展開填寫：
     - `Google OAuth Client ID` 輸入框
     - `Google OAuth Client Secret` 輸入框
     - 【💾 儲存憑證】按鈕
     - 【🔗 開啟 Google Cloud 憑證控制台】連結教學
   - 儲存完成後立即點擊【登入 Google】，無縫解決「無法使用雲端同步」痛點。
3. **雲端同步方向 (三選一)**：
   - 雙向同步、從雲端拉取、推送到雲端。
