# 設計規劃書：iOS PWA 名片編輯表單、照片更新、外部匯出與雲端同步介面 (ISSUE-0049)

- **對應 Issue ID**：`ISSUE-0049`
- **設計版本**：`v0.1`
- **設計工程師角色**：設計工程師 Agent（交由 PM Agent 統一與人類使用者確認）

---

## 1. 設計目標與使用情境

1. **設計目標**：
   - 延續 iOS Human Interface Guidelines (HIG) 風格，針對 iPhone X (375×812 pt) 至最新 iPhone 的螢幕比例、瀏海／動態島與底部手勢橫條（Safe Area Insets）進行優化。
   - 提供直覺流暢的**名片編輯與新增表單**、**照片選取／拍照預覽**、**一鍵匯出 iPhone 通訊錄**以及**一鍵備份同步至 Google Drive**。
2. **關鍵情境**：
   - **情境 A（外出即時編輯）**：使用者在會議或拜訪客戶時，打開 iPhone MajiOCR，點進名片詳情點擊「✏️ 編輯」，修改電話、新增 Email 或補充談話備註，點擊儲存，本機快取與搜尋清單即時更新。
   - **情境 B（新增名片與拍照）**：使用者收到實體名片，點擊「➕ 新增名片」，輸入姓名與公司，點擊「拍攝名片正面」，直接呼叫 iPhone 相機拍照並自動附加為名片原圖。
   - **情境 C（匯出至手機通訊錄）**：在名片詳情點擊「📇 加入手機通訊錄」，iPhone Safari 即刻跳出原生聯絡人對話框，點擊「儲存」直接寫入 iPhone 內建通訊錄。
   - **情境 D（同步回雲端）**：修改多筆名片後，打開「載入 / 同步」面板，點擊「📤 上傳最新備份至 Google Drive」，系統在 3 秒內自動打包並上傳至雲端，其他 Windows 或 Android 裝置隨即能看到最新版本。

## 2. 介面視覺與元件設計

### 2.1 頁面新增按鈕與入口
1. **頂部導覽列 (Header Bar)**：
   - 於 `header-bar` 右側（或搜尋列旁）新增 **`➕ 新增`** 按鈕（高對比圓角按鈕，高度 36px，符合觸控標準）。
2. **名片詳情對話框 (Detail Modal)**：
   - 頂部動作列新增：
     - **`✏️ 編輯名片`**：點擊開啟編輯對話框。
     - **`📇 加入手機通訊錄 (.vcf)`**：產生並下載/分享該聯絡人之 vCard。
     - **`🗑️ 刪除名片`**：標記軟刪除並提示復原。
3. **載入 / 同步面板 (Sync Modal)**：
   - 新增 **「區塊 ③：📤 備份匯出與雲端同步」**：
     - `[ 📤 上傳最新備份至 Google Drive ]`（主行動按鈕，藍底白字）。
     - `[ 📦 匯出備份壓縮包 (.zip) ]`（次行動按鈕，支援 AirDrop / 儲存至 iPhone 檔案）。
     - `[ 📇 匯出全部聯絡人為 vCard (.vcf) ]`。

### 2.2 名片編輯／新增表單對話框 (`editModal`)
採用 iOS 原生風格的半屏／全屏彈出式面板（Bottom Sheet / Modal Sheet）：
- **頂部 Header**：
  - 左側 `[ 取消 ]` 按鈕，中間標題 `編輯名片` / `新增名片`，右側 `[ 儲存 ]` 強調按鈕。
- **照片上傳區（雙格排列）**：
  - 正面照片格：若有既有圖片顯示預覽縮圖＋「更換」與「刪除」按鈕；若無顯示「📷 拍攝/選取正面」。
  - 反面照片格：若有既有圖片顯示預覽縮圖＋「更換」與「刪除」按鈕；若無顯示「📷 拍攝/選取反面」。
- **基本資訊區塊 (Card Section)**：
  - 姓名（必填，字級 16px 防止 iOS Safari 縮放）。
  - 公司名稱、職稱。
- **聯絡資訊動態清單 (Dynamic Value Section)**：
  - 每一筆項目含：類型下拉選單（電話、電子郵件、地址、網站）、內容輸入框、刪除按鈕。
  - 底部提供 `[ ➕ 新增聯絡方式 ]` 快捷按鈕。
- **分類標籤區塊 (Tags Section)**：
  - 既有標籤膠囊（點擊切換選取／取消狀態）。
  - 自訂新增標籤輸入框（輸入標籤名稱後按 Enter 或點擊新增）。
- **備註區塊 (Notes)**：
  - 多行文字輸入框（`textarea`），最小高度 80px。

## 3. 狀態反饋與防呆機制

- **必填驗證**：儲存時若姓名為空，震動並醒目提示「請輸入姓名」。
- **同步防呆**：若未登入 Google Drive，點擊「上傳最新備份至 Google Drive」自動引導先點擊「Google 帳號登入授權」。
- **Toast 提示**：
  - 儲存成功：「✅ 名片資料已更新並保存於本機」。
  - 上傳成功：「☁️ 最新備份包已成功上傳至 Google Drive！」。
  - 匯出成功：「📦 備份壓縮包已就緒」。
