## 1. 介面視覺與使用者體驗規劃

### 1.1 選單佈局與操作動線

在「已存名片總覽」之操作工具列中：
1. **匯入選單入口**：
   - 於 `_exportSyncBtn` 下拉選單最頂層（或與匯出並列），新增：
     - **📥 匯入名片資料 (Excel / CSV)...**
2. **匯出選單項目擴充**：
   - 在匯出區段新增：
     - **📊 匯出 Excel 工作表 (*.xlsx)**（帶有 Excel 綠色主題視覺聯想）
     - **📁 匯出完整名片 CSV (*.csv)**（相容 UTF-8 BOM，全部屬性欄位）
     - 保留原有的 Outlook CSV、Google CSV 與 vCard 匯出選項。

```
[已存名片總覽 工具列]
[🔍 搜尋...] [🏷️ 標籤篩選] [⚙️ 管理標籤] [↔️ 自動欄寬] [🔄 資料庫同步] [📤 匯出 / 匯入 ▾]
                                                                        ├─ 📥 匯入名片 (Excel / CSV)...
                                                                        ├─────────────────────────────
                                                                        ├─ 📊 匯出 Excel 工作表 (*.xlsx)
                                                                        ├─ 📁 匯出完整名片 CSV (*.csv)
                                                                        ├─ 📁 匯出 Outlook 聯絡人 (*.csv)
                                                                        ├─ 📁 匯出 Google 聯絡人 (*.csv)
                                                                        └─ 📇 匯出通用名片檔 (*.vcf)
```

---

### 1.2 匯入互動對話框：`ImportContactsDialog`

對話框採用 WinUI 3 現代化流暢卡片設計，包含四個清晰的操作區段：

```
+---------------------------------------------------------------------------------+
| 📥 批次匯入名片資料 (Excel / CSV)                                                |
+---------------------------------------------------------------------------------+
| [InfoBar] 支援標準 Excel (*.xlsx) 與通用 CSV (*.csv) 格式，系統將自動比對欄位標題。    |
|                                                                                 |
| 1. 檔案與範本                                                                    |
|    [📂 瀏覽選取檔案...]    已選檔案：D:\Contacts_2026.xlsx (共偵測到 35 筆資料)   |
|    [📄 下載標準 Excel 範本]   [📄 下載標準 CSV 範本]                              |
|                                                                                 |
| 2. 重複資料處理策略                                                               |
|    (o) ⏩ 跳過重複名片（同姓名且同公司或同電話時，自動略過不匯入）- 推薦            |
|    ( ) 🔄 覆蓋更新現有（以匯入資料更新系統現有名片，補齊未填欄位）                |
|    ( ) ➕ 一律建立為新名片（允許同名重複建立獨立名片記錄）                       |
|                                                                                 |
| 3. 資料預覽 (前 5 筆)                                                            |
|    +-----+--------+----------+----------+-------------+------------------+     |
|    | #   | 姓名   | 公司     | 職稱     | 電話/手機   | Email            |     |
|    +-----+--------+----------+----------+-------------+------------------+     |
|    | 1   | 王小明 | 甲式科技 | 研發經理 | 0912-345678 | ming@example.com |     |
|    | 2   | 李大華 | 乙式電訊 | 業務總監 | 0988-112233 | hua@example.com  |     |

|                                                                                 |
| [🚀 開始匯入 (35 筆)]                                                 [關閉]     |

```

### 1.3 互動反饋與狀態流轉

- **解析階段**：選取檔案後立即在背景非同步進行串流讀取與標題智慧對齊，完成後即時更新「已選檔案資訊」與「前 5 筆預覽清單」，若格式錯誤或缺少必要欄位（如無姓名欄位）以紅色 InfoBar 提示警告。
- **匯入執行階段**：點擊「開始匯入」後按鈕呈現 Loading 轉圈，完成後彈出摘要通知：
  - 「🎉 匯入完成！成功處理 35 筆：新增 30 筆，更新 3 筆，略過 2 筆重複名片。」
- **就地刷新**：對話框關閉後自動刷新名片資料表與分類標籤群組。
