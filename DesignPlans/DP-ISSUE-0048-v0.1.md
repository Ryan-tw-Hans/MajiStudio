# 設計規劃書：Windows 端行動版設定對話框 UI / 排版重構 (ISSUE-0048)

* **文件編號**：DP-ISSUE-0048-v0.1
* **關聯 Issue**：[`ISSUE-0048`](../IssueLog/IssueLog.sqlite3)
* **設計目標**：徹底消除文字/控制項重疊、改善過窄壅擠版面、提供卡片化與高質感的雙模式設定體驗。
* **版本**：v0.1
* **建立日期**：2026-10-17

---

## 1. 介面視覺尺度與排版規格

| 元件 / 區塊 | 原設計（有缺陷） | 新設計規格（優化後） | 設計目的 |
| :--- | :--- | :--- | :--- |
| **對話框寬度** | 預設 (~548px)，`rootStack` 寫死 560px | `ContentDialog.MaxWidth = 720`，內容寬度彈性延伸 (640~680px) | 提供足夠橫向空間，文字不折斷、按鈕不裁切 |
| **頂部模式切換列** | StackPanel (Horizontal)，兩按鈕固定寬度溢出截字 | 2 欄等寬 Grid (`1*`, `1*`)，按鈕 Stretch 填滿，Padding 10px | 兩模式清晰對稱，文字完整顯示，具備清晰選取狀態 |
| **模式按鈕選取狀態** | 僅切換 FontWeight (Normal / SemiBold) | 選取時使用 Accent 色系或深色邊框/陰影，未選取時為幽靈按鈕風格 | 一眼看出目前所處模式 |
| **提示方塊 (Intro)** | 缺乏明確上下間距，文字緊迫 | 圓角 8px，Padding 14px，字型大小 13px，行距舒適 | 作為清晰的指引橫幅，不與下方步驟產生衝突 |
| **步驟卡片 (Step 1~3)** | 內部間距 8px，無獨立層次 | 獨立卡片 (Border)，Padding 16px，內部 Spacing 12px，卡片間距 14px | 步驟區塊分明，層次清晰 |
| **輸入框標題與提示** | 塞入 `TextBox.Header`，長文字換行引發元件重疊 | 標題與附註說明獨立呈現，輸入框高度標準化 | 避免 WinUI 3 TextBox 換行測量 Bug |
| **按鈕尺寸與觸控區** | 緊貼上方輸入框，部分被遮蔽 | 與上方輸入框保持至少 14px Margin，Padding 12px | 視覺開闊，防止任何元件疊加 |
| **QR Code 容器** | 210~240px 居中但與周圍間距小 | 220px 居中，柔和外框與圓角 12px，白底陰影 | 聚焦掃描視覺重心 |
