## 1. 測試項目與驗證標準

| 測試編號 | 測試項目 | 驗證標準與預期結果 |
| :--- | :--- | :--- |
| **TC-01** | 對話框寬度與視窗自適應 | 對話框 `MaxWidth` 為 720px，水平寬度充足，不出現內部水平均擠變形，文字不會被強制截斷。 |
| **TC-02** | 頂部模式切換按鈕文字完整性 | 「🌟 推薦：官方公用免設定版 (GitHub Pages)」與「⚡ 自訂：部署至個人 Vercel」兩大按鈕並排等寬展示，字體完整呈現無省略號 (`...`)。 |
| **TC-03** | 雙模式切換流暢度與無重疊殘影 | 切換 GitHub Pages 模式與 Vercel 模式時，面板切換乾淨俐落，完全無文字圖層疊加、按鈕重疊或直接穿透之現象。 |
| **TC-04** | Vercel 步驟 2 部署按鈕排版 | 「🚀 一鍵導入專案並發布至 Vercel」按鈕完整位於輸入框下方，具有充足垂直間距 (至少 12px)，完全不遮蔽上方輸入框。 |
| **TC-05** | 功能完整性與回歸測試 | 網址複製、在瀏覽器開啟、QR Code 產生與重新產生、Vercel 部署等原有功能均正常運作，關閉對話框時設定值正確持久化。 |
