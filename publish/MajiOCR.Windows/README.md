# MajiOCR.Windows 0.1.0-beta.33 (本機雙資料庫同步整併與功能選單同步中心升級)

目前為本機發布版，更新日期為 2026-10-18（Asia/Taipei）。
直接執行本資料夾的 `MajiOCR.Windows.exe`。維持單一免安裝、自含執行檔（Self-Contained Single-File Executable）及離線 OCR 模型，並內嵌完整 `MajiOCR.Web` (`0.2.0-beta.1`) 靜態 PWA 資產包。

### 本版更新重點 (`ISSUE-0053`)
1. **主畫面功能選單直接同步入口**：
   - 主視窗右上角「`...`」功能選單緊鄰「備份名片資料」與「還原名片資料」處新增「🔄 同步名片資料庫 (本機/雲端)...」，讓使用者在首頁即可一鍵開啟同步中心。
2. **本機雙資料庫同步整併 (雙檔案 / 備份檔)**：
   - 同步中心新增「📁 本地端檔案同步」推薦模式，支援自由選取隨身碟、本機或雲端同步資料夾內的 SQLite 資料庫檔 (`*.sqlite3`, `*.db`) 或備份壓縮包 (`*.zip`)。
   - 支援三種本機同步方向：「雙向整併同步（智慧比對兩端並回寫兩側）」、「從外部檔案整併至本機」及「從本機整併至外部檔案」。
3. **雲端同步就地設定與登入優化**：
   - 於「☁️ Google Drive 雲端同步」分頁直接內嵌「⚙️ Google OAuth 憑證設定」展開區塊，支援就地填寫 Client ID / Client Secret、保存設定並一鍵登入，提供快速控制台教學連結，解決未設憑證無法同步之問題。
4. **全管道無縫串接差異比對裁決與安全快照**：
   - 本機與雲端同步全面串接專業雙欄對照比對 UI、時間戳記較新判定、差異色塊高亮與「兩側同時保留 (Keep Both)」，整併前自動於 `backups/` 建立快照備份。
