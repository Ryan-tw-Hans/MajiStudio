# MajiOCR.Windows 0.1.0-beta.35 (支援 Excel 與 CSV 批次匯入匯出與智慧重複裁決)

目前為本機發布版，更新日期為 2026-10-19（Asia/Taipei）。
直接執行本資料夾的 `MajiOCR.Windows.exe`。維持單一免安裝、自含執行檔（Self-Contained Single-File Executable）及離線 OCR 模型，並內嵌完整 `MajiOCR.Web` (`0.2.0-beta.1`) 靜態 PWA 資產包。

### 本版更新重點 (`0.1.0-beta.35`)
1. **新增 Excel (*.xlsx) 與通用 CSV (*.csv) 批次匯出**：
   - 「已存名片總覽」工具列與主選單全面支援一鍵將名片匯出為包含全部屬性欄位（姓名、公司、部門、職稱、電話、手機、Email、地址、統編、網站、標籤、備註、建立時間）之標準 Excel 活頁簿 (*.xlsx) 與通用 CSV (*.csv，內嵌 UTF-8 BOM，以 Excel 開啟不亂碼）。
2. **新增「📥 批次匯入名片資料 (Excel / CSV)」功能**：
   - 支援選取 `.xlsx` 與 `.csv` 表格檔案，具備智慧標頭對齊能力（自動精準對應繁中、簡中與英文欄位）。
   - 提供「📄 下載標準 Excel 範本」與「📄 下載標準 CSV 範本」按鈕。
   - 內建前 5 筆資料即時預覽與筆數校驗。
3. **靈活的重複名片裁決策略**：
   - 支援三種策略：⏩ **跳過重複名片 (推薦)**、🔄 **覆蓋更新現有**（補齊欄位與標籤聯集）、➕ **一律建立為新名片**。
4. **資料庫交易與自動安全備份**：
   - 批次匯入由 SQLite Transaction 完整包裹，匯入前自動在 `backups/` 建立快照備份，提供強健的防呆與錯誤復原防護。
5. **採用 MiniExcel 輕量純託管引擎**：
   - 引入純 C# 託管 MiniExcel (v1.46.0，MIT 授權)，完全相容於單一自含執行檔與隨身碟可攜式模式。
