- **審核角色**：SA 系統架構師、設計工程師、軟體工程師、DBA、測試工程師

## 1. 背景與問題陳述

MajiStudio (`MajiOCR.Windows`) 目前在「已存名片總覽」已支援將名片匯出為 Outlook CSV、Google CSV 及 vCard (.vcf) 格式。然而在日常商務人脈管理情境中，使用者提出兩項關鍵缺口：
1. **缺少通用 Excel (*.xlsx) 匯出**：許多商務使用者習慣以 Microsoft Excel 表格整理與統計聯絡人，需要一鍵匯出包含完整名片屬性欄位（姓名、公司、職稱、電話/手機、Email、地址、統一編號、分類標籤、備註、建立日期等）之標準 Excel 活頁簿。
2. **缺乏批次匯入功能 (Excel / CSV)**：使用者常有來自既有客戶清單、活動簽到表、業務交接表或第三方系統匯出之 Excel / CSV 檔案，目前無批次匯入管道，只能逐筆手動新增或 OCR，大幅增加建檔成本。

經 PM Agent 釐清，使用者確認本階段規格重點如下：
- **目標平台**：以 Windows 桌面端 (`MajiOCR.Windows`) 為主。
- **檔案格式**：同時支援 Excel (`*.xlsx`) 與通用 CSV (`*.csv`) 之匯入與匯出。
- **重複處理**：批次匯入時若偵測到與現有名片重複（同名同公司或同名同電話），提供三種處理策略供使用者彈性選取（跳過重複、覆蓋更新現有、一律新增為新名片）。
- **欄位比對**：具備智慧標題比對能力（自動識別繁中/簡中/英文等常見欄位名稱），並內建「下載標準匯入範本 (Excel / CSV)」功能。

---

## 2. 需求目標

1. **匯出功能擴充**：
   - 於名片管理介面之匯出選單中，新增：
     - 📁 **匯出 Excel 表單 (*.xlsx)**：輸出標準 OpenXML 活頁簿，表頭包含完整欄位，樣式整潔易讀。
     - 📁 **匯出完整名片 CSV (*.csv)**：輸出包含完整欄位之 UTF-8 with BOM CSV 檔案，確保 Excel 開啟不亂碼。
   - 支援匯出目前搜尋/篩選結果或全部名片。

2. **批次匯入功能建置**：
   - 於名片管理介面提供 **「📥 匯入名片 (Excel / CSV)...」** 操作入口。
   - 支援使用者選取 `.xlsx` 或 `.csv` 檔案。
   - 提供「📥 下載標準範本」按鈕，可一鍵產生並儲存空白範本（含範例資料列）。
   - **智慧欄位比對**：系統自動比對檔案表頭與名片標準欄位（姓名、公司、部門、職稱、手機、公司電話、Email、地址、統編、網站、分類標籤、備註等）。
   - **匯入預覽與設定對話框**：
     - 顯示檔案解析結果與前 N 筆預覽。
     - 提供重複資料裁決選項：
       1. ⏩ **跳過重複名片**（若系統已有同名且同公司或同電話者，略過不匯入）。
       2. 🔄 **覆蓋更新現有**（以匯入資料更新現有名片，空欄位不覆蓋已有內容）。
       3. ➕ **一律建立為新名片**（即使重複亦建立獨立名片記錄）。
   - **交易安全與匯入報表**：
     - 匯入過程採用 SQLite Transaction 保護，確保全部成功或安全回滾。
     - 匯入完成後顯示結果摘要（成功筆數、更新筆數、略過筆數、失敗筆數與錯誤詳情）。

## 3. 驗收條件 (Acceptance Criteria)

- **AC-01 [匯出 Excel]**：在已存名片總覽點擊「匯出 Excel 表單 (*.xlsx)」，能順利儲存為 `.xlsx` 檔案，以 Excel 開啟無格式損毀或警告，包含姓名、公司、職稱、電話、Email、地址、標籤等完整欄位。
- **AC-02 [匯出完整 CSV]**：點擊「匯出完整名片 CSV (*.csv)」，輸出之 CSV 帶有 UTF-8 BOM，欄位包含引號與逗號轉義，Excel 雙擊開啟正常顯示中文。
- **AC-03 [匯入入口與範本]**：在已存名片總覽提供「📥 匯入名片 (Excel / CSV)...」入口；匯入視窗內建「下載 Excel 範本」與「下載 CSV 範本」按鈕，能產生標準欄位範本。
- **AC-04 [智慧欄位解析]**：上傳 `.xlsx` 或 `.csv` 時，表頭不論繁體中文（如「姓名」、「手機」）、英文（如 "Name", "Mobile"）或常見同義詞均能自動映射至系統欄位。
- **AC-05 [重複處理裁決]**：使用者可切換「跳過重複」、「覆蓋更新」或「建立新名片」，系統依選取策略正確執行新增、更新或略過。
- **AC-06 [資料庫交易與回報]**：匯入過程若遇資料損毀或格式異常，能維持資料庫一致性並回報清晰錯誤訊息；匯入完成即時刷新清單與標籤面板。
- **AC-07 [單一檔案相容性]**：新增套件（MiniExcel）必須與 .NET 10 單一免安裝執行檔 (`PublishSingleFile`) 100% 相容，無原生 DLL 遺漏問題。
