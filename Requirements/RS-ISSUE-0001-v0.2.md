## 1. 已確認目標與範圍

系統是在 Android 手機上拍攝或選取名片影像，使用 OCR 將內容轉為可編輯的聯絡人資訊。辨識模式依使用者選擇分為離線 OCR、雲端 OCR 與 AI 結構化解析。

本版已確認：

1. 離線 OCR 預設可用；雲端 OCR 與 AI 只在使用者主動啟用並同意資料傳送後使用。
2. 相機對焦可用後，即開始以最新影格做離線 OCR，持續更新未鎖定候選。
3. 使用者點選候選文字後，文字與目前欄位對應會被鎖定，不再受即時 OCR 覆寫。
4. 使用者再次點選 Locked 文字時，只解除該項目並要求重新掃描。
5. 使用者鎖定文字後，可用欄位名稱下拉選單將它重新分類。
6. 使用者按下完成後，完整的結構化聯絡人資訊必須寫入手機 App 私有 SQLite，供後續查詢系統使用。

本版不代表 Android App、雲端帳號、API 金鑰、資料庫加密或正式部署已建立。

## 2. 主要使用流程

1. 使用者開啟相機預覽並將名片放入取景框，也可從裝置選取既有影像。
2. App 顯示對焦與取景提示。當相機對焦可用且可分析時，開始離線即時 OCR。
3. App 僅更新未鎖定的候選文字，並將候選映射到姓名、公司、職稱、電話、電子郵件、網站、地址或未分類欄位。
4. 使用者點選候選文字，將其值與欄位對應鎖定。
5. 若欄位名稱錯誤，使用者在 Locked 狀態下以欄位名稱下拉選單重新分類；這不會重新辨識文字。
6. 使用者再次點選 Locked 文字，可讓該項重新加入掃描；其他 Locked 欄位維持不變。
7. 使用者可手動新增、刪除或編輯所有欄位。
8. 使用者可選擇雲端 OCR 或 AI 解析；每次資料離開手機前都必須顯示同意說明與取消選項。
9. 使用者按下完成後，App 以單一交易將已確認的資訊存入本機 SQLite。
10. App 可選擇將同一筆資料送往 Android 系統聯絡人編輯畫面，由使用者最後確認；SQLite 已存檔不等於 Android Contacts 已成功新增。

## 3. 功能需求

| ID | 需求 |
| --- | --- |
| FR-01 | App 必須支援相機預覽拍攝單張名片與相簿選取影像。雙面名片是否納入第一版為待決事項。 |
| FR-02 | App 必須處理影像方向、取景引導、重拍與裁切。影像模糊或文字不足時，必須提供重拍與手動輸入，不得把低可信結果當成已確認值。 |
| FR-03 | 離線 OCR 為初始選項；在飛航模式下，拍攝、即時 OCR、欄位鎖定、手動編輯、完成存檔與本機查詢均須可用。 |
| FR-04 | 相機對焦可用時，App 必須啟動即時 OCR；一次僅可執行一個分析工作，新影格必須取代排隊的舊影格，避免 OCR 工作阻塞預覽。 |
| FR-05 | 硬體未提供可靠對焦狀態或持續無法取得清晰結果時，App 必須顯示對焦提示，並提供手動掃描或拍照後辨識的退路。 |
| FR-06 | OCR 模組必須保留當次暫存的候選文字、位置資訊與版本號，讓晚到的 OCR 結果無法覆寫新一代結果或 Locked 欄位。 |
| FR-07 | 候選文字必須具有 Live、Locked、RescanRequested 狀態。只有 Live 項目可由新的 OCR 結果更新。 |
| FR-08 | 使用者點選 Live 候選後，App 必須鎖定其文字值與目前欄位。Locked 項目不得被背景 OCR、自動欄位解析或雲端結果覆寫。 |
| FR-09 | 使用者再次點選 Locked 項目後，App 必須只解除該項目並要求重新掃描；在取得新有效候選前保留舊值供使用者保留、修改或取消。 |
| FR-10 | Locked 項目必須提供欄位名稱下拉選單，可選姓名、公司、職稱、電話、電子郵件、網站、地址、備註或未分類。重新分類不得重新執行 OCR。 |
| FR-11 | 若目標欄位已有 Locked 值，重新分類時必須由使用者選擇保留既有值、加入另一筆值或取代；不得靜默覆寫。 |
| FR-12 | 使用者必須能手動新增、修改或刪除任何欄位；OCR 成功不是完成存檔的必要條件。 |
| FR-13 | 雲端 OCR 與 AI 必須由使用者主動觸發。每次傳送前顯示服務名稱、傳送資料類型、隱私說明與取消選項；不得自動改送其他供應商。 |
| FR-14 | AI 解析預設傳送 OCR 文字；若要傳送名片影像，必須取得另一層影像傳送同意。 |
| FR-15 | 完成操作必須以單一資料庫交易將聯絡人主資料與多筆電話、電子郵件、網址、地址等子資料寫入 App 私有 SQLite。交易失敗時不得留下半筆完成資料。 |
| FR-16 | SQLite 中的完成聯絡人資料是後續查詢系統的結構化來源；查詢必須經 App 的資料存取層，不能直接暴露資料庫檔案。 |
| FR-17 | 名片影像、即時影格與未鎖定的完整原始 OCR 文字預設只作當次記憶體或暫存使用；完成後不持久保存。未來若要保存它們，必須另立需求與保存期限。 |
| FR-18 | 第一版可使用 Android 新增聯絡人 Intent 開啟系統聯絡人編輯畫面；App 必須分別追蹤本機 SQLite 存檔結果與 Android Contacts 匯出結果。 |

## 4. 即時 OCR 與欄位鎖定狀態

| 狀態 | 進入條件 | 可更新範圍 | 離開條件 |
| --- | --- | --- | --- |
| Focusing | 相機啟動、焦點不穩或名片未在取景框 | 不覆寫任何欄位 | 對焦可用、使用者手動掃描或選取既有影像 |
| Live | 分析可執行 | 僅未鎖定候選可由最新 OCR 結果更新 | 使用者鎖定、停止掃描或離開取景 |
| Locked | 使用者點選候選文字 | 值與欄位名稱固定；仍可手動編輯或重新分類 | 使用者再次點選該項 |
| RescanRequested | 使用者再次點選 Locked 項目 | 只允許此項等待新候選；其他 Locked 項目不變 | 新候選出現、使用者取消或手動輸入 |
| Completed | 完成交易已成功 | 不再被本次掃描更新 | 由未來查詢／編輯需求處理 |

即時 OCR 的節流、候選穩定判定與相機硬體差異，必須以目標裝置測試決定；不得承諾每個影格、每台手機或每種名片都能即時更新。

## 5. 本機 SQLite 資料範圍

| 資料 | 完成後是否保存 | 用途 |
| --- | --- | --- |
| 已確認的姓名、公司、職稱、備註 | 是 | 本機聯絡人查詢。 |
| 已確認的電話、電子郵件、網址、地址 | 是，可多筆 | 本機聯絡人查詢。 |
| 資料來源模式與完成時間 | 是 | 追溯資料由手動、OCR 或 AI 建立。 |
| Android Contacts 匯出狀態 | 是 | 區分本機已存檔與系統聯絡人已建立。 |
| 名片影像、即時影格、完整 OCR 原文 | 否，預設 | 降低敏感資料保存。 |
| GPT、Gemini、雲端 OCR 的長期 API 金鑰 | 否 | 不得存入 App 或 SQLite。 |

## 6. 非功能需求與驗收方向

| ID | 需求／來源 | 驗證方式與通過標準 | 責任 |
| --- | --- | --- | --- |
| NFR-01 | 離線優先與隱私 | 飛航模式下可完成即時 OCR、鎖定、手動編輯、SQLite 存檔與查詢；未同意時封包不得出現名片資料。 | 測試 |
| NFR-02 | 即時互動穩定性 | OCR 分析延遲或新影格到達時，預覽不被阻塞；Locked 值不變；RescanRequested 只影響指定項目。 | 軟體／測試 |
| NFR-03 | 資料完整性 | 成功完成後，主資料與多筆子欄位在 App 重啟後可查；交易失敗後不可查到半筆資料。 | DBA／測試 |
| NFR-04 | 最小化保存 | 完成後 SQLite 不含名片影像或未經核准的完整 OCR 原文，且資料庫位於 App 私有儲存範圍。 | DBA／測試 |
| NFR-05 | 同意可理解性 | 雲端 OCR、AI 文字與 AI 影像三種傳送情境均有不同提示；取消後不得發出請求。 | 設計／測試 |
| NFR-06 | 安全 | APK、原始碼、SQLite、日誌與錯誤回報不含供應商長期 API key 或 ChatGPT 登入憑證。 | 軟體／測試 |
| NFR-07 | 可用性 | 使用者可從空白草稿完成資訊，且任何 Locked 欄位均可編輯、重新分類或重掃。 | 設計／測試 |

## 7. 角色影響與不在範圍

| 面向 | 判定 | 理由 |
| --- | --- | --- |
| SA | 適用 | 新系統加入即時影像分析、欄位狀態機、SQLite 與外部服務邊界。 |
| 設計工程師 | 適用 | 對焦提示、候選鎖定、重掃、重分類與衝突處理皆為核心互動。 |
| DBA | 適用 | 完成資料需進 App 私有 SQLite，供後續查詢。 |
| 系統整合 | 適用 | Android Contacts、雲端 OCR、AI 與 Gateway 都是跨系統介面。 |
| 維運 | 有條件適用 | 只有啟用 Gateway 或付費 AI 時，才需要機密、費用、監控與輪替作業。 |
| 測試 | 適用 | 需驗證即時狀態、資料庫交易、本機查詢、同意與故障回復。 |

本版不包含 iOS、桌面程式、Web 查詢網站、名片影像或完整 OCR 原文的永久保存、多人帳號、同步、分享、匯出、任意第三方 AI URL、雲端帳號建立、API 金鑰設定或正式發布。
