# 需求規格書：ISSUE-0060 已存名片詳細抽屜「確認欄位明細」支援單一欄位原地行內編輯（Inline Editing）

- **文件識別碼**：`RS-ISSUE-0060-v0.1`
- **關聯 Issue**：`ISSUE-0060`
- **建立日期**：`2026-10-30`
- **負責角色**：PM Agent
- **審核角色**：SA 系統架構師、設計工程師、軟體工程師、測試工程師

---

## 1. 背景與問題陳述

在 MajiStudio Windows 桌面端 (`MajiOCR.Windows`) 之「已存名片總覽」介面中，使用者點擊名片後，右側會展開詳細資訊抽屜（Drawer），顯示名片影像縮圖、分類標籤以及「確認欄位明細」（包含姓名、公司、職稱、電話、Email、地址、備註等欄位）。

目前使用者若欲修改特定欄位（如修正筆誤電話、微調職稱或更新姓名），必須點擊上方的「返回主畫面編輯 / 重新辨識」按鈕，這會將名片重新載入為草稿並切換至全螢幕掃描辨識頁面，打斷使用者的瀏覽與清單審閱流程。

經 PM Agent 釐清，使用者明確選定 **「方案 A：原地行內編輯（Inline Editing）」**：
在右側抽屜各欄位旁提供獨立編輯圖示 ✏️，點擊後即可原地切換為輸入框直接修改並儲存，無需切換畫面。

---

## 2. 需求目標與功能範圍

1. **欄位旁編輯圖示**：
   - 於右側詳細資訊抽屜之「確認欄位明細」列表中，每筆欄位右側顯示直覺的編輯圖示按鈕 ✏️（附帶 Tooltip「編輯此欄位」）。
   - 若名片處於待刪除狀態 (`PendingDelete`)，編輯按鈕自動停用。

2. **原地行內切換編輯模式**：
   - 使用者點擊 ✏️ 圖示後，該欄位文字區域原地切換為 `TextBox` 輸入框，並自動獲得焦點（Focus）且預先全選原有內容。
   - 於輸入框下方或右側提供：
     - **「✔️ 儲存」按鈕**（高亮 Accent 樣式，支援按鍵盤 `Enter` 快速觸發儲存）。
     - **「❌ 取消」按鈕**（支援按鍵盤 `Escape` 快速放棄修改並返回檢視狀態）。
     - **錯誤訊息提示列**（紅字，當驗證未通過或儲存失敗時顯示）。

3. **資料驗證與防呆**：
   - 若使用者未作任何修改即點擊儲存，自動返回檢視狀態，不發動無效存檔。
   - 若欄位內容被清空（純空白），提示「欄位內容不可為空白」並阻擋儲存，避免誤刪關鍵屬性。
   - 儲存過程中停用儲存與取消按鈕，顯示「儲存中...」防止重複點擊。

4. **資料庫交易與版本遞增 (ACID & Revision CAS)**：
   - 使用現有安全之 `IStorageService.SaveDraftAsync` 儲存管線，以 CAS (Compare-And-Swap) 樂觀鎖將名片修訂版本號（`Revision`）加 1，更新時間更新為當前時間。
   - 保持圖片資產雜湊與關聯不變。

5. **UI 即時聯動更新**：
   - 儲存成功後，右側詳細抽屜自動刷新：
     - 欄位明細切換回檢視模式並顯示新值。
     - 若修改的是「姓名」或「公司」，抽屜頂部的大標題 (`DisplayTitle`) 與副標題 (`DisplaySubtitle`) 同步刷新。
     - 版本標籤（如 `版本: rev.3`）與儲存時間即時更新。
   - 左側名片表格（`_tableListView`）保留原選取項目，並同步重新載入當前分頁，使表格欄位即時呈現最新值。

## 3. 驗收條件 (Acceptance Criteria)

- **AC-01 [編輯圖示呈現]**：開啟已存名片右側抽屜，「確認欄位明細」之每筆欄位右方皆可看見 ✏️ 圖示按鈕，且滑鼠懸停顯示說明提示。
- **AC-02 [原地行內切換]**：點擊 ✏️ 圖示後，該欄位文字就地變為輸入框，且鍵盤輸入焦點直接落在輸入框內。
- **AC-03 [取消編輯]**：點擊「❌ 取消」按鈕或按下 `Esc` 鍵，該欄位無損復原為原文字檢視模式。
- **AC-04 [鍵盤快速儲存]**：在輸入框修改內容後按 `Enter` 鍵或點擊「✔️ 儲存」，能成功發送存檔請求。
- **AC-05 [空白防呆]**：若將內容清空並嘗試儲存，顯示「欄位內容不可為空白」錯誤訊息且不發動存檔。
- **AC-06 [資料庫持久化與版本更新]**：儲存後 SQLite 資料庫中該欄位內容已正確更新，且 `revision` 遞增，抽屜版本資訊與更新時間隨之更新。
- **AC-07 [左側清單即時同步]**：修改「姓名」、「公司」、「職稱」、「電話」或「Email」等欄位後，左側表格對應行之文字亦同步更新，且表格選取狀態不丟失。
