# MajiOCR.Windows 變更紀錄

## [0.1.0.33] - 2026-10-18
- 主視窗右上角「...」功能選單緊鄰備份與還原處新增「同步名片資料庫 (本機/雲端)...」直接入口 (ISSUE-0053)
- 同步中心升級為跨管道「名片資料庫同步中心」，支援「📁 本地端檔案同步」與「☁️ Google Drive 雲端同步」雙模式
- 本機端雙資料庫同步：支援使用者自由瀏覽選取外部 SQLite 資料庫檔 (*.sqlite3, *.db) 或備份檔 (*.zip)，提供「雙向整併同步」、「從外部整併至本機」及「從本機整併至外部」三種方向
- 雲端同步易用性優化：直接於雲端同步介面內嵌「⚙️ Google OAuth 憑證設定」展開區塊，支援就地填寫 Client ID / Secret、保存並一鍵登入，徹底解決未設定憑證導致雲端同步無法使用的痛點
- 本機與雲端同步皆全面無縫串聯 DatabaseMergeDialog 專業四態差異比對、較新判定與兩側同時保留 (Keep Both) 裁決機制

## [0.1.0.32] - 2026-10-18
- 支援多裝置同步時之資料庫整併與衝突差異比對 (ISSUE-0052)
- 比對引擎精準分類四態：本機獨有、外部新增、完全一致、內容衝突
- 衝突名片清晰並列顯示本機與外部更新時間戳記，並標註「🟢 較新 (Newer)」領先時間徽章與差異欄位高亮
- 支援靈活裁決策略：【一鍵以較新時間為準】、【全部保留本機】、【全部採納外部】與【👥 全部兩側同時保留 (Keep Both)】
- 「兩側同時保留」自動為外部衝突版本派生新 UUID，加註「(同步複本)」並複製獨立圖檔與標籤關聯，達成 100% 零資料遺失
- 整併前自動建立本地安全快照備份至 backups/，整併作業於單一交易中原子化落實，支援失敗完整 Rollback
- 全面整合至本機離線 ZIP 還原與 Google Drive 雲端同步下載流程，提供使用者自由選擇「整併」或「覆蓋」

## [0.1.0.31] - 2026-10-18
- 設定檔完全可攜化（Portable Mode）：將 settings.json 與 custom-fields.json 改為存放於主程式同一目錄下，不再跨目錄共用 %LocalAppData%\MajiOCR.Windows 全域設定與舊自訂欄位 (ISSUE-0051)
- 新資料庫免沿用舊密碼詢問：啟動時以同目錄 contacts.sqlite3 檔案實際 SQLCipher 加密標頭作為是否要求主密碼解鎖之唯一真相來源；將主程式移至無資料庫或未加密資料庫之資料夾時不再誤彈出密碼詢問視窗
- 支援原工作目錄（同目錄已存在 contacts.sqlite3）首次啟動時自動將舊版設定檔平滑遷移至主程式同目錄

## [0.1.0.30] - 2026-10-17
- 強化本機執行時憑證安全：Google OAuth ClientSecret (google_oauth_config.json) 與 Vercel Access Token (settings.json) 全面改採 Windows DPAPI (CryptProtectData CurrentUser) 加密儲存，並支援既有明文設定自動平滑升級 (ISSUE-0050)
- 清理公開儲存庫敏感與環境資訊：移除診斷測試中的本機絕對路徑、測試姓名與舊版 Google Drive 資源識別碼，將規格文件連結統一改為相對路徑，並將內部 IssueLog.sqlite3 移出 Git 公開追蹤

## [0.1.0.29] - 2026-10-17
- iOS PWA (MajiOCR.Web v0.2.0-beta.1) 升級支援名片資料編輯、新增名片與照片拍攝/選取 (ISSUE-0049)
- 內建瀏覽器端 WebAssembly SQLite 引擎 (sql.js) 與 Pure-JS ZIP 打包器，支援將修改後的名片資料庫與圖檔直接打包為標準 MajiOCR_Backup_iOS_*.zip
- 支援 SQLCipher-AES256 雙向加解密：若備份受主密碼保護，修改後自動使用 WebCrypto 重新逐頁加密並注入 HMAC-SHA512 校驗
- 支援「📤 備份匯出與 Google Drive 雲端同步」：新增 Google Drive REST API Multipart Upload 雙向同步上傳至 MajiOCR_Backups 資料夾
- 支援「📦 匯出備份壓縮包 (.zip)」透過 iOS 原生 Web Share API 儲存至 iPhone 檔案、iCloud Drive 或 AirDrop
- 支援「📇 匯出名片為 vCard (.vcf)」供 iPhone 原生系統通訊錄 (Apple Contacts) 一鍵匯入

## [0.1.0.28] - 2026-10-17
- 優化「📱 iOS / Web 行動版設定與部署」對話框視覺排版與尺寸限制 (ISSUE-0048)
- 顯式擴大對話框寬度（MaxWidth = 720px）並支援自適應延伸，徹底解決模式切換按鈕文字遭強制裁切問題
- 頂部模式切換列改採 1 列 2 欄 Grid 等寬平分佈局，清楚標示當前選取模式
- 移除 ContentDialog 內部冗餘嵌套的 ScrollViewer，由外層單一責任管線接管滾動，徹底消除文字與控制項重疊穿透之殘影現象
- 重構步驟 1~3 表單欄位：將長說明文字從 TextBox.Header 拆出為獨立副標，杜絕按鈕疊在輸入框之上的排版缺陷

## [0.1.0.27] - 2026-10-17
- 新增 iOS / Web 行動版雙模式對話框：整合「🌟 官方免設定版 (GitHub Pages)」與「⚡ 自訂部署 (Vercel)」(ISSUE-0047)
- 預設提供 GitHub Pages 官方公用版進入點與即時 240x240 高解析度 QR Code，使用者 iPhone 相機一掃即可加入主畫面
- 新增 GitHub Pages 網址設定持久化與自訂網址即時生成 QR Code 功能
- 支援 GitHub Actions 自動化工作流程 (.github/workflows/deploy-pages.yml) 發布 MajiOCR.Web 靜態資產

## [0.1.0.26] - 2026-10-17
- 全面廢止 Google Drive 更新來源與手動 manifest 流程，改採 GitHub Releases 作為軟體自動檢查與更新機制 (ISSUE-0046)
- 軟體更新管理員原生支援解析 GitHub Releases API (api.github.com/repos/Ryan-tw-Hans/MajiStudio/releases/latest)，自動讀取最新版本、Markdown 變更紀錄與 ZIP 下載連結
- 加入既有使用者設定檔平滑遷移：自動將舊有的 Google Drive 更新網址切換為官方 GitHub Releases API
- 建立 GitHub Actions 工作流程 (.github/workflows/release.yml)，支援推送標籤自動於雲端編譯、打包並發布至 GitHub Releases

## [0.1.0.25] - 2026-10-16
- 修復名片草稿資料欄位（TextBox 等輸入框）使用 Ctrl+V 貼上文字時，誤觸發全域「貼上圖片」快捷鍵並彈出未偵測到有效圖片提示的問題 (ISSUE-0045)
- 新增鍵盤快捷鍵焦點判斷與攔截處理（OnPasteKeyboardAcceleratorInvoked），嚴密區隔文字編輯與圖片載入作業
- 修復 GitHub 首頁 README.md 中 Mermaid 流程圖語法相容性問題，消除 rich display 渲染異常 (reading 'render')

- 新增 iOS / iPhone (iPhone X / iOS 16+) 跨平台行動網頁版 PWA (MajiOCR.Web v0.1.0-beta.1) 並內嵌於 Windows 單一執行檔中 (ISSUE-0044)
- 新增「📱 部署 iOS / Web 雲端版 (Vercel)...」3 步驟一鍵部署精靈：引導註冊/登入 Vercel 並取得 Token，自動透過 Vercel REST API 建立專案並上傳 PWA 靜態包，自動產生 iPhone 掃描安裝 QR Code
- iPhone PWA 支援「Google Drive 雲端直接下載」與「iPhone 檔案 App 選取備份包 (.zip/.sqlite3)」雙管道載入
- 內建瀏覽器端 WebCrypto SQLCipher 4 (SQLCipher-AES256) 主密碼解密與 HMAC-SHA512 驗證引擎，與 Windows 加密備份 100% 相容，並支援 IndexedDB 本機離線持久化、複合關鍵字搜尋、分類標籤篩選與 vCard (.vcf) 聯絡人匯出

- 自訂欄位全面持久化至 SQLite 資料庫（contacts.sqlite3）：新增 custom_field_definitions 資料表，廢止純本機 JSON 設定檔，換機、備份還原與匯出 100% 完整保留
- 歷史設定平滑遷移：自動偵測並遷移既有 custom-fields.json 入庫
- 內嵌 Change Log 支援：更新管理對話框支援內嵌變更紀錄回退，單檔 EXE 執行環境下亦能直接檢視完整更新歷程
