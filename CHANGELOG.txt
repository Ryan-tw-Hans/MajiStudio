# MajiOCR.Windows 變更紀錄

## [0.1.0.24] - 2026-10-16
- 新增 iOS / iPhone (iPhone X / iOS 16+) 跨平台行動網頁版 PWA (MajiOCR.Web v0.1.0-beta.1) 並內嵌於 Windows 單一執行檔中 (ISSUE-0044)
- 新增「📱 部署 iOS / Web 雲端版 (Vercel)...」3 步驟一鍵部署精靈：引導註冊/登入 Vercel 並取得 Token，自動透過 Vercel REST API 建立專案並上傳 PWA 靜態包，自動產生 iPhone 掃描安裝 QR Code
- iPhone PWA 支援「Google Drive 雲端直接下載」與「iPhone 檔案 App 選取備份包 (.zip/.sqlite3)」雙管道載入
- 內建瀏覽器端 WebCrypto SQLCipher 4 (SQLCipher-AES256) 主密碼解密與 HMAC-SHA512 驗證引擎，與 Windows 加密備份 100% 相容，並支援 IndexedDB 本機離線持久化、複合關鍵字搜尋、分類標籤篩選與 vCard (.vcf) 聯絡人匯出

## [0.1.0.23] - 2026-09-30
- 登入後自動檢查更新與提醒：無論有無主密碼保護，登入就緒後背景自動掃描 Google Drive 雲端更新，發現新版主動彈出通知對話框提示升級
- 自訂欄位全面持久化至 SQLite 資料庫（contacts.sqlite3）：新增 custom_field_definitions 資料表，廢止純本機 JSON 設定檔，換機、備份還原與匯出 100% 完整保留
- 歷史設定平滑遷移：自動偵測並遷移既有 custom-fields.json 入庫
- 內嵌 Change Log 支援：更新管理對話框支援內嵌變更紀錄回退，單檔 EXE 執行環境下亦能直接檢視完整更新歷程

## [0.1.0.22] - 2026-09-30
- 主頁面頂部選項排版重構：精簡核心功能按鈕並固定顯示文字標籤，新增獨立 Fluent 卡片式辨識語系與畫面控制列
- 選單項目完整整合：新增備份（本機 ZIP 封裝/雲端）、還原（本機 ZIP/雲端）以及三種格式聯絡人匯出（Outlook CSV、Google Contacts CSV、通用 vCard）與雲端同步
- 整合 Google Drive 軟體自動更新機制 (ISSUE-0042)
- 主畫面工具列新增「🔄 檢查軟體更新」按鈕與更新管理對話框 (WinUI 3 ContentDialog)
- 支援背景下載、SHA-256 完整性雜湊校驗與獨立 updater 套用重啟
- 套用更新時嚴格排除並保護使用者的 SQLite 資料庫（contacts.sqlite3）、設定檔與名片圖片
- 支援透過 publish-targets.json 與發布選單發布至指定 Google Drive 帳號

## [0.1.0.21] - 2026-09-30
- 修復主程式目錄 ACL 權限相容性與還原防護 (ISSUE-0041)
- 支援 Google Drive 歷史備份清單密碼保護狀態標記
- 支援 SQLCipher 資料庫加密與主密碼防護
